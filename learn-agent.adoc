= NetApp Workload Factory のAIエージェントについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Workload Factory AIOpsはAIを活用して環境を分析し、改善策を提案します。承認すれば、設定した認証情報と権限を使用して操作を実行することもできます。


NOTE: アカウント管理者がAI機能を無効にしている場合、メッセージが表示され、エージェントを使用できなくなります。管理者に連絡するか、link:manage-genai-features.html["AI管理について学ぶ"]。



[[before-you-begin]]
== 開始する前に

Workload Factory アカウントに AWS 認証情報と、エージェントがアクセスするリソースに必要な IAM 権限が付与されていることを確認してください。読み取り/書き込みモードを有効にする場合は、それらの権限でサポートされている変更も許可する必要があります。

link:add-credentials.html["AWS認証情報を追加し、IAM権限を設定する方法を説明します。"^]。



[[data-usage-and-privacy]]
== データ利用とプライバシー

お客様のデータはAIモデルの学習には使用されません。エージェントは、お客様の認証情報を使用して標準のAWS APIを介してAWSリソースに安全にアクセスし、お客様の実際の環境に基づいて応答します。すべてのエージェント活動は、NetAppのプライバシーポリシーおよびAWSセキュリティ管理に従います。



[[why-use-ai-agents]]
== AIエージェントを使用する理由

AIエージェントは、Workload Factoryでの作業効率向上を支援します。

* お客様の環境に基づいた回答と推奨事項を入手できます。
* リスクと最適化の機会を特定します。
* 問題のトラブルシューティングと承認されたアクションの実行を、単一のワークフローで行います。
* スケジュールされたチェックを実行し、チャット履歴で最新情報を受け取ることができます。
* FSx for ONTAP とオンプレミス ONTAP 環境全体で作業します。




[[access-the-ai-agents]]
== AIエージェントにアクセスする

「Ask Me」ホームページから:: 「Ask Me」ランディングページで、「Explore Agents」を選択してください。AIエージェントのサイドパネルが開き、エージェントの機能を紹介するウェルカムメッセージが表示されます。
エージェントのリダイレクトリンクから:: **「質問する」**機能やその他の機能を使用する際、より高度なサポートを受けるためにエージェントへリダイレクトされるリンクが表示される場合があります。




[[how-ai-agents-work]]
== AIエージェントの仕組み



[[how-agents-access-your-environment]]
=== エージェントが環境にアクセスする方法

エージェントは、現在の Workload Factory のスコープに含まれており、link:manage-agent-settings.html["エージェント設定"]で選択された認証情報によってサポートされている場合にのみリソースにアクセスできます。エージェントは、両方の制御が適用される場所でのみ動作できます。アクセスできるリソースは、AWS 認証情報に割り当てられた権限によっても異なります。デフォルトではすべての認証情報が選択されますが、設定済みの認証情報の一部に絞り込むこともできます。

現在のスコープには以下が含まれます：

* *AWSアカウント*：エージェントがアクセスできるAWSアカウント。
* *認証情報*：エージェントが使用できる認証情報。
* *リージョン*：エージェントがアクセスできる AWS リージョン。


NetApp Workload Factoryのフィルタは、表示するAWSアカウントやリージョンなど、現在のページの範囲を設定します。エージェント設定では、エージェントがその範囲内で使用できる認証情報を制御します。リソースへのアクセスは、それらの認証情報に割り当てられたIAM権限にも依存します。


NOTE: 「エージェント設定」で認証情報を選択しても、追加のAWS権限は付与されません。エージェントが分析または管理するリソースにアクセスするために必要なIAM権限が、認証情報に付与されていることを確認してください。



[[read-only-mode-default]]
=== 読み取り専用モード（デフォルト）

デフォルトでは、エージェントは読み取り専用モードで動作します。このモードでは、以下のことが可能です。

* お客様の環境に関する質問に回答します。
* FSx for ONTAPのファイルシステム、データベース、ワークロードを分析します。
* リスク、設定ミス、および最適化の機会を特定します。
* パフォーマンス、可用性、保護、およびコスト効率を向上させるための推奨事項を提示します。
* 問題のトラブルシューティングを行い、修復手順を提案します。


読み取り専用モードでは、リソースを変更することはできません。書き込みアクセスが必要な操作をリクエストした場合、エージェントは制限事項を説明し、エージェントの設定へのリンクを表示します。



[[read-write-mode-opt-in]]
=== 読み書きモード（オプトイン）

link:manage-agent-settings.html["エージェント設定"]で読み取り/書き込み機能を有効にすることができます。このモードでは、エージェントがサポートされている各操作について説明し、変更を行う前にお客様の承認を必要とします。

この承認プロセスは、Slack 統合および NetApp Console を含むすべてのエージェントエクスペリエンスに適用されます。



[[what-users-see-when-ai-agents-have-no-data-or-activity]]
== AIエージェントにデータやアクティビティがない場合にユーザーが見るもの

エージェントがクレデンシャルを持っていなくても、一般的なガイダンスを提供することは可能です。ただし、お客様のリソースをレビューしたり、お客様の環境に特化したインサイトを提供したりすることはできません。
