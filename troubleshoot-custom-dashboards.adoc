= カスタムダッシュボードのトラブルシューティング
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
この情報を使用して、カスタムダッシュボードの作成時または使用時に発生する可能性のある一般的な問題を解決してください。



== ダッシュボードの作成に失敗しました

**問題：** ダッシュボードを作成する際に、「リクエストの理解とコードの生成に失敗しました」というエラーメッセージが表示されます。

**原因：** システムはリクエストを理解できなかったか、プロンプトからビジュアライゼーションを作成できませんでした。

**解決策：** 次のことを試してください：

* 監視したい内容について、より明確な詳細を盛り込んでリクエストを書き直してください。
* link:create-custom-dashboard.html["カスタムダッシュボードを作成する"]のサンプルプロンプトのいずれかから始めてください。
* 複雑な監視ニーズを、よりシンプルな複数のダッシュボードに分割します。
* 追跡したいワークロード、メトリクス、期間、またはディメンションを指定してください。




== ダッシュボードのデータ読み込みに失敗しました

**問題：** ダッシュボードは作成されましたが、データの読み込み時にエラーが表示されます。

**原因：**これは通常、権限の問題またはデータソースが利用できないために発生します。

**解決策：**

* **権限を確認してください：** ワークロードファクトリーアカウントに、ダッシュボードで使用されるワークロードとリソースへの読み取りアクセス権があることを確認してください。権限要件については、link:learn-custom-dashboards.html#permissions["権限"]を参照してください。
* **認証情報の確認：** AWS認証情報が有効であり、有効期限が切れていないことを確認してください。詳細については、link:add-credentials.html["AWSクレデンシャルを追加"]を参照してください。
* **ワークロード構成の確認：** 監視対象のワークロードがWorkload Factoryで正しく構成され、現在実行中であることを確認してください。




== ダッシュボードが読み込まれない、または読み込みが遅い

**問題：** ダッシュボードの読み込みが遅い、または一部のウィジェットが表示されない。

**原因：** 読み込みが遅い原因としては、ネットワークの問題、大量のデータ、または一時的なサービス遅延などが考えられます。

**解決策：**

* **インターネット接続を確認してください：** インターネット接続が安定していることを確認してください。
* **ブラウザを更新してください：** ページを更新して、ダッシュボードが正しく読み込まれるかどうか確認してください。
* **ブラウザのキャッシュとCookieをクリアしてください：** これにより、古いデータや破損したデータが原因で発生する読み込みの問題を解決できる場合があります。
* **しばらく待ってからもう一度試してください：** 問題が解決しない場合は、数分待ってからもう一度試してください。




== ダッシュボードを編集できません

**問題：** ダッシュボードを編集しようとすると、「現在、[ユーザー名]によって編集中です」というメッセージが表示されます。

**原因：** Workload Factoryアカウントの別のユーザーがダッシュボードを編集しています。ダッシュボードを編集できるのは、一度に1人のユーザーのみです。

**解決策：**

* 他のユーザーが変更を終えて保存するまで待ってください。
* 編集作業の調整については、メッセージに記載されている担当者にご連絡ください。
* ユーザーが編集作業を終了したにもかかわらずロックが解除されない場合は、編集ウィンドウを閉じてロックを解除するようにユーザーに促してください。




== ダッシュボードが見つかりません

**問題：** 作成したダッシュボードがダッシュボードカタログに表示されなくなりました。

**原因：** Workload Factory アカウントの別のユーザーが削除した可能性があります。

**解決策：**

* 正しい Workload Factory アカウントにログインしていることを確認してください。
* アカウント内の他のユーザーに、誰かがダッシュボードを削除したかどうか尋ねてみてください。
* 必要に応じて、元の要件に基づいてダッシュボードを再作成してください。


Workload Factoryアカウントのすべてのユーザーは、カスタムダッシュボードを表示および削除できます。共有ダッシュボードを管理する際は、チームと連携してください。
