= NetApp Workload Factory の Tracker で操作を監視する
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
FSx for ONTAP、クレデンシャル、リンク操作の実行を監視および追跡し、NetApp Workload Factory の Tracker でタスクの進捗状況を監視します。

.タスクの内容
Workload Factory は、監視機能である Tracker を提供しており、FSx for ONTAP、クレデンシャル、およびリンク操作の進捗状況とステータスを監視および追跡し、操作タスクとサブタスクの詳細を確認し、問題や障害を診断することができます。

Trackerでは、いくつかの操作が可能です。ジョブは、期間（過去24時間、7日間、14日間、または30日間）、ワークロード、ステータス、およびユーザーでフィルタリングしたり、検索機能を使用してジョブを検索したり、ジョブテーブルをCSVファイルとしてダウンロードしたりできます。Trackerはいつでも更新できます。また、失敗した操作をすぐに再試行したり、失敗した操作のパラメータを編集して再度操作を試行したりすることもできます。

Trackerは、運用状況に応じて2段階の監視レベルをサポートしています。ファイルシステム展開などの各タスクには、タスクの説明、ステータス、開始時刻、タスクの実行時間、ユーザー、リージョン、プロキシリソース、タスクID、および関連するすべてのサブタスクが表示されます。APIレスポンスを確認することで、操作中に何が起こったのかを理解できます。

トラッカーのタスクレベルと例::
+
--
* レベル1（タスク）：ファイルシステムの展開状況を追跡します。
* レベル2（サブタスク）：ファイルシステム展開に関連するサブタスクを追跡します。


--
動作状況:: Trackerにおける操作ステータスは、_進行中_、_成功_、_失敗_の3つです。
+
--
動作周波数:: 稼働頻度は、ジョブの種類とジョブスケジュールに基づいて決定されます。


--
イベント保持:: イベントはユーザーインターフェースに30日間保持されます。




[[track-and-monitor-operations]]
== 業務を追跡および監視する

Tracker を使用して NetApp Console での操作を追跡および監視します。

.手順
. いずれかの方法でログインしてくださいlink:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["コンソールエクスペリエンス"^]。
. メニュー image:workloads-menu-icon.png["ハンバーガー メニュー アイコンは、storage、eda、ai、databases、vmware、administration などのワークロードに移動するために使用されます。"] を選択し、次に「管理」を選択します。
. 管理メニューから*Tracker*を選択します。
. Trackerでは、フィルターまたは検索を使用してジョブ結果を絞り込むことができます。また、ジョブレポートをダウンロードすることもできます。




[[view-api-request]]
== APIリクエストを表示する

TrackerのタスクのAPIリクエストをCodeboxで確認できます。

.手順
. Trackerでタスクを選択します。
. アクションメニューを選択し、次に「APIリクエストの表示」を選択します。




[[retry-a-failed-operation]]
== 失敗した操作を再試行する

Trackerで失敗した操作を再試行します。失敗した操作のエラーメッセージをコピーすることもできます。


NOTE: 失敗した操作に対しては、x回までしか再試行できません。

.手順
. Trackerで、失敗した操作を選択します。
. アクションメニューを選択し、次に*再試行*を選択してください。


.結果
操作が再開されました。



[[edit-and-retry-a-failed-operation]]
== 失敗した操作を編集して再試行する

失敗した操作のパラメータを編集し、Tracker の外で操作を再試行してください。

.手順
. Trackerで、失敗した操作を選択します。
. アクションメニューを選択し、次に*編集して再試行*を選択します。
+
操作ページにリダイレクトされますので、そこでパラメータを編集して操作を再試行できます。



.結果
操作が再開されました。Tracker にアクセスして、操作のステータスを確認してください。
