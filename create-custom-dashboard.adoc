= カスタムダッシュボードを作成する
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
監視したい内容を平易な言葉で記述することで、カスタムダッシュボードを作成できます。AIがセットアップ手順を案内し、ダッシュボードがワークロードと優先順位に合うようにします。

.タスクの内容
カスタムダッシュボードは、AIによる対話を通じて、ユーザーが視覚化したい内容を理解します。監視ニーズを自然言語で説明すると、システムが確認のための質問を投げかけ、ダッシュボードが要件を満たしていることを確認します。

作成後、ダッシュボードを更新すると最新のデータが表示されます。

カスタムダッシュボードは設計上読み取り専用であり、ストレージやワークロードの設定を変更することはできませんのでご注意ください。

.開始する前に
* ダッシュボードで監視したいリソースにアクセスするには、権限が必要です。
* ワークロードを監視するためのダッシュボードを作成する前に、Workload Factory でワークロードを設定してください。




== ダッシュボードを作成する

.手順
. いずれかを使用してログインしlink:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["コンソールエクスペリエンス"^]ます。
. メニュー image:workloads-menu-icon.png["ハンバーガー メニュー アイコンは、storage、eda、ai、databases、vmware、administration などのワークロードに移動するために使用されます。"] を選択し、*ワークロードの概要* > *カスタムダッシュボード* を選択します。
+
これが初めてのダッシュボードの場合は、開始に役立つサンプルプロンプトが表示された空白の画面が表示されます。*プロンプトをコピー*を選択すると、サンプルプロンプトがAIダイアログのテキストボックスにコピーされます。

. 「新しいダッシュボードを作成」を選択します。
. AIダイアログで、監視したい内容を説明してください。
+
分かりやすい言葉で説明してください。AIは、お客様のニーズをより深く理解するために、いくつか質問をさせていただきます。

. image:arrow.png["メニューアイコンはダッシュボードの生成を開始するために使用されます。, width=18"]を選択します。
. AIからの質問に回答してください。
+
AIは、ニーズをより深く理解するために、いくつかの選択肢の中から選択するよう求める場合があります。各質問に回答し、「続行」を選択するか、「スキップ」を選択してオプションの質問をスキップしてください。

. すべての質問に回答したら、*Continue* を選択してダッシュボードを作成してください。


.結果
作成したカスタムダッシュボードがダッシュボードカタログに追加されました。Workload Factoryアカウントのすべてのユーザーが、それにアクセスして閲覧できます。

.次の手順
作成後、以下のことが可能です：

* 最新の情報を確認するには、ダッシュボードのデータを更新してください。
* ダッシュボードを編集して表示内容を変更する
* 不要になったダッシュボードを削除する
* ダッシュボードの詳細（作成者や最終更新日時など）を表示します
